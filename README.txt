AMRUTHA VINUKONDA — PREMIUM ENGINEERING PORTFOLIO

HOW TO PREVIEW
Open index.html in Chrome, Edge or Firefox.

HOW TO PUBLISH ON GITHUB PAGES
1. Your GitHub account username must be amruthavinukonda if you want the URL https://amruthavinukonda.github.io.
2. Create a PUBLIC repository called amruthavinukonda.github.io.
3. Upload index.html, style.css, script.js and the complete assets folder into the repository ROOT (not inside an extra folder).
4. In repository Settings > Pages > Build and deployment select Deploy from a branch, main, /(root), Save.
5. Wait a few minutes and open your GitHub Pages URL.

CUSTOMIZATION
- Text and section order: edit index.html.
- Colors, spacing and typography: edit style.css.
- Mobile menu and interactive image gallery: script.js.
- Images and résumé: assets folder.
- For new photos, add files to assets and replace image src paths in index.html.
